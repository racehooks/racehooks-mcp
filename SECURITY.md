# Security Policy

## Supported versions

Only the latest release of `@racehooks/mcp` is supported. Please upgrade before reporting.

## Reporting a vulnerability

Please do not open a public issue for security problems. Report privately by either:

- Using GitHub private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.
- Emailing contact@racehooks.io with the subject "Security".

We aim to acknowledge reports within 3 business days.
